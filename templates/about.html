About QR Threat Scanner

AI Powered Cyber Security Solution

Project Overview

QR Threat Scanner is a cybersecurity-based web application that scans QR code images, extracts the embedded content, and analyzes URLs for potential cyber threats. The system helps users identify phishing websites, malicious QR codes, unsafe links, and suspicious domains before opening them.

Key Features

  • ✔ Scan QR Code Images
  • ✔ Decode QR Code Content
  • ✔ Detect Website URLs
  • ✔ AI-Based Threat Analysis
  • ✔ HTTPS Verification
  • ✔ Detect Suspicious Keywords
  • ✔ Detect URL Shorteners
  • ✔ Detect IP Address URLs
  • ✔ Risk Score (0 - 100)
  • ✔ Threat Level Classification
  • ✔ Safe Website Direct Access
  • ✔ Continue Anyway Warning Popup
  • ✔ Cyber Security Dashboard

Technologies Used

Frontend HTML5, CSS3, JavaScript
Backend Python Flask
QR Decoder Pyzbar + Pillow
Programming Python
Security Analysis Custom URL Analyzer
Deployment Render / Railway / GitHub

Cyber Security Checks

  • HTTPS Verification
  • URL Shortener Detection
  • Suspicious Keywords
  • IP Address Detection
  • Multiple Subdomains Detection
  • Long URL Detection
  • Double Slash Detection
  • @ Symbol Detection

Project Objective

The primary objective of QR Threat Scanner is to improve cyber awareness and protect users from malicious QR codes. By analyzing URLs before opening them, the system reduces the risk of phishing, credential theft, malware downloads, and fake login attacks.
